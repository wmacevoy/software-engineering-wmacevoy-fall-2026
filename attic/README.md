# attic

Things kept for reference that are not part of the live system. Nothing here is built, tested, or
maintained, and nothing in `parking/` may depend on it.

## `parking/`

The original parking-occupancy demo, exactly as it arrived from a programming-languages course,
generated by a coding agent from the prompt preserved at the end of its `README.md`.

It is kept as a before-picture. It works, it is readable, and a conventional review would pass it —
and measured against `../parking/REQUIREMENTS.md` it has no device identity, no structured logging,
no notion of an old reading, and a customer view that presents a possibly-hours-old count as fact.

That distance is the point of the course. This is what "it works" looks like before anyone asks
what happens when the inputs misbehave.

It still runs on its own:

```sh
cd attic/parking && docker compose up --build
```
